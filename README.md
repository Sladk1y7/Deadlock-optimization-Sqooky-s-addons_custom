# Deadlock Optimization \& Custom Addons Pack

A ready-to-use optimization build for **Deadlock**, combining **Sqooky's** optimized configuration (`gameinfo.gi`) with full support for custom addons and mods.

## 📌 Features

* **Maximum FPS \& Frame Time Stability:** Optimized rendering parameters with non-essential GPU/CPU workloads disabled (shadows, post-processing, anti-aliasing).
* **Mod \& Addon Support:** Custom search paths configured in `gameinfo.gi` to seamlessly load custom content from the `addons` folder.
* **Pre-configured Directory Structure:** Ready-to-use file organization for quick installation.

## 🛠️ Installation Guide

1. Download the archive or clone this repository.
2. Navigate to your Deadlock root game folder. By default, the path is:

```text
   C:\\\\Program Files (x86)\\\\Steam\\\\steamapps\\\\common\\\\Deadlock\\\\game\\\\citadel
   ```

3. Replace your existing `gameinfo.gi` with the one provided in this repository.
4. Place your custom mod files, textures, or sounds into the `addons` directory:

```text
   citadel/addons
   ```

5. Launch the game!
